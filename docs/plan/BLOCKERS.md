# Engeller (BLOCKERS)

> Kural ([AGENTS.md §5](../../AGENTS.md#5-döngü-önleme-kuralları-ihlal--görev-iptal)): Aynı sorun için en fazla 3 farklı hipotez denenir. 3. denemeden sonra görev `BLOCKED` olarak buraya kaydedilir ve bağımsız bir sonraki göreve geçilir.

Şu anda kayıtlı açık engel yok.

---

  1. Hipotez A → sonuç
  2. Hipotez B → sonuç
  3. Hipotez C → sonuç
- **Son hata çıktısı:**
  ```
  ...
  ```
- **Önerilen sonraki adım:** ...
